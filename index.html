It opens your file. It never takes it.

No upload endpoint

This site is static files. The viewer is a set of ES modules running in your tab, so a scene has nowhere to be sent.

Read from a local handle

Your pick becomes a browser-local object URL. The viewer streams from it exactly as it would from the network, progress bar and all.

Checked before it loads

Only the first few kilobytes are read first, with every count bounds-checked, so a file that cannot open gets a sentence you can act on.

Gone when the tab is

Nothing is cached server-side, and the local handle is released as soon as decoding ends.

How it renders

One clock drives everything

A moving scene is one continuous model evaluated at a single time value in the shader — positions move along each splat’s velocity, opacity follows its temporal gate, colour follows spherical harmonics × a Fourier series in time. Audio is slaved to the same clock.

Adaptive resolution, never adaptive truth

When a device cannot hold the frame rate, render resolution drops and climbs back when it can. Splats are not thrown away to keep up.

WebGL2 by default, WebGPU on request

WebGL2 is the path everywhere. Add ?gpu=1 to sort and draw with WebGPU compute where the browser genuinely reports an adapter.

It stops when you are not looking

Scroll the viewer off screen and it pauses; scroll back and it resumes. Frames that would not change are not redrawn.

From 2D to immersive

  1. Default. The scene renders inline: orbit, pan, zoom, scrub.
  2. Feature detection. WebXR immersive-vr and immersive-ar are checked separately; a button appears only for a mode your device supports.
  3. Immersive. The session starts inside your click. The scene stands upright on the floor in front of you; in VR select the floor to teleport, in AR select a surface to place it, pinch with both hands to scale.
  4. Back to 2D. Ending the session returns to the inline view where you left it.

Share and embed

The viewer is a set of plain ES modules — no build step. Every view can be a link.

A link to a moment

viewer/?scene=lumen&t=2.500&cam=…

The Copy link to this view button in the viewer’s help panel writes the time and camera into the URL.

An iframe

<iframe src="https://YOUR-SITE/viewer/?scene=URL&ui=min"
  allow="xr-spatial-tracking; fullscreen"></iframe>

The module

import { mountViewer } from './viewer/js/index.js';
const viewer = mountViewer(el, {
  scene: 'scenes/my.nx4d',
  onEvent: (type, data) => console.log(type, data),
});
viewer.seek(1.5);

Query options: scene, format, t, cam, yaw/pitch/roll/dolly, up=z, ui=min, gpu=1, sh=0…3, muted=0, xr=0, perf=full, pool=N.
